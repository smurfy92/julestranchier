Site vitrine personnel de Jules Tranchier (julestranchier.com), Next.js 16 App Router + React 19, Tailwind CSS v4 et Framer Motion. Aucun backend, aucune base de données, aucune API : tout le contenu vit dans un unique module TypeScript (src/data/content.ts) rendu par des composants de section. Trois routes (accueil one-page, CV imprimable, mentions légales) plus les routes SEO générées (sitemap, robots, image Open Graph).
